Overview

Project Summary

This project combines virtualization, routing, switching, remote access, Linux services, storage, monitoring, and security tooling into one documented environment. The goal is to demonstrate the full lifecycle of infrastructure work: design, deployment, administration, troubleshooting, hardening, and recovery planning.

Implementation

What I Built

  • Deployed Proxmox VE as the virtualization platform for Windows and Linux workloads.
  • Configured pfSense for inter-VLAN routing, NAT, DHCP, DNS, firewall policy, and remote access.
  • Created segmented networks for management, home devices, guests, and security workloads.
  • Implemented WireGuard VPN and SSH key authentication for secure administration.
  • Deployed Docker, Portainer, Samba NAS, Omada Controller, Wazuh, Cowrie, and Uptime Kuma.
  • Maintained technical documentation and troubleshooting procedures for the environment.

Lessons learned

Key Takeaways

  • Segmentation is most effective when rules are tested from both trusted and untrusted networks.
  • Monitoring and documentation reduce troubleshooting time and make changes easier to validate.
  • Secure administration requires both network controls and strong authentication practices.
