Project Summary

A Windows Server 2022 domain environment built to demonstrate administration, controlled attack simulation, hardening, and validation.

Implementation

What I Built

  • Deployed AD DS and DNS.
  • Designed OUs, users, groups, and administrative roles.
  • Joined Windows 11 systems to the domain.
  • Performed controlled Kali attack simulations.
  • Applied Group Policy, least privilege, password policies, and hardening.

Lessons Learned

Key Takeaways

  • Identity design affects usability and attack surface.
  • Hardening should be validated through repeat testing.
