Implementation

What I Built

  • Deployed Proxmox VE for Windows and Linux workloads.
  • Configured pfSense for VLAN routing, NAT, DHCP, DNS, firewall policy, and remote access.
  • Implemented WireGuard, SSH keys, Docker, Portainer, Samba NAS, Omada, Wazuh, Cowrie, and Uptime Kuma.

Lessons Learned

Key Takeaways

  • Segmentation must be tested from trusted and untrusted networks.
  • Monitoring and documentation reduce troubleshooting time.
