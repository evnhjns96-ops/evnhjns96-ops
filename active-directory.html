Overview

Project Summary

The Active Directory lab models a small organization with departmental organizational units, users, groups, service accounts, and domain-joined Windows workstations. The project demonstrates both administrative responsibilities and the security consequences of weak identity and access controls.

Implementation

What I Built

  • Deployed a Windows Server 2022 domain controller with Active Directory Domain Services and DNS.
  • Designed departmental OUs, user accounts, groups, and administrative roles.
  • Joined Windows 11 systems to the domain and validated centralized authentication.
  • Performed controlled attack simulations from Kali Linux to identify common weaknesses.
  • Applied Group Policy, least privilege, password policies, and account hardening controls.
  • Repeated testing after hardening and documented the remediation process.

Lessons learned

Key Takeaways

  • Identity design and administrative delegation affect both usability and attack surface.
  • Hardening is stronger when controls are validated through repeat testing.
  • Clear documentation is essential when tracking configuration and security changes.
