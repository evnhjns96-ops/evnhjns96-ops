# Evan Jones Portfolio Website v3

A responsive, multi-page GitHub Pages portfolio focused on systems administration, networking, and cybersecurity.

## Included pages

- `index.html` — Main portfolio
- `enterprise-infrastructure.html` — Enterprise infrastructure case study
- `active-directory.html` — Active Directory security case study
- `security-operations.html` — SIEM, IDS, and honeypot case study
- `kali-pentest.html` — Penetration testing case study
- `styles.css` — Shared styling
- `script.js` — Mobile navigation, reveal animations, and current year
- `assets/Evan_Jones_Resume.docx` — Downloadable resume

## Publish

1. Back up the current GitHub Pages repository.
2. Upload all files and the `assets` folder to the root of `evnhjns96-ops`.
3. In **Settings → Pages**, deploy from the `main` branch and `/ (root)`.
4. Wait for GitHub Pages to rebuild.

## Before publishing

Review all claims for accuracy and sanitize every screenshot and document. Do not publish credentials, private keys, public IP addresses, VPN configuration exports, firewall backups, or unredacted sensitive information.
