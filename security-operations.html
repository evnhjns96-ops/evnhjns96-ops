Overview

Project Summary

This project focuses on building visibility into infrastructure activity. Wazuh collects endpoint and server telemetry, pfSense forwards firewall logs, Suricata adds network intrusion detection, and Cowrie captures unauthorized SSH activity in an isolated network segment.

Implementation

What I Built

  • Deployed Wazuh manager, dashboard, and agents across Linux and infrastructure systems.
  • Integrated pfSense firewall logs for centralized analysis.
  • Configured Suricata IDS to generate network security alerts.
  • Deployed Cowrie in a dedicated VLAN with restricted access to trusted networks.
  • Reviewed authentication events, attacker commands, firewall activity, and service health.
  • Used monitoring results to refine firewall rules and operational documentation.

Lessons learned

Key Takeaways

  • Useful alerts require context, tuning, and understanding of normal system activity.
  • Honeypots must be isolated so observation does not create unnecessary risk.
  • Combining endpoint, firewall, and network telemetry provides stronger visibility than any single source.
